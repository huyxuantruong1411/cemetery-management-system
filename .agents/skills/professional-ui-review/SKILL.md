# Professional UI/UX Review Guidelines

1. **Design Tokens & Dignified Aesthetics:**
   - Palette: Ivory white `#F7F8F5`, Charcoal `#1F2933`, Deep Green `#24594D`, Warm Amber for warning, Crimson for error.
   - Typography: Clean, modern fonts with complete Vietnamese diacritic support (Noto Sans / Be Vietnam Pro / Inter).
   - No flashy/frivolous animations, glassmorphism overuse, or disrespectful funerary imagery.

2. **The 4 Essential States:**
   - **Loading:** Shimmer / Skeleton placeholders, never raw blank screens.
   - **Normal:** Clear hierarchy, right-aligned monetary values, badges for statuses (Kim Tinh, Contract state).
   - **Empty Data:** Empathetic, informative empty state with actionable Call to Action (CTA).
   - **Error:** Clear Vietnamese error description with actionable "Thử lại" (Retry) button.

3. **Responsive & Field Usability:**
   - Web tested at 1440x900 (Desktop), 768x1024 (Tablet), 390x844 (Mobile).
   - Mobile tap targets >= 48px, one-handed field checklist workflow for Caretakers.
   - Contrast compliant with WCAG AA standard.
